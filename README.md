# Shameer Mananthody — Systems Engineer & IT Solutions Specialist Portfolio

A modern, responsive Single Page Application (SPA) portfolio and Admin CMS dashboard built with modern web technologies and real-time Supabase PostgreSQL cloud sync.

## ✨ Features
- **Modern Dark UI**: Designed with Slate 900 palette, cyan/indigo glowing accents, glassmorphism, and responsive Lucide icons.
- **Dynamic Supabase Cloud Sync**: Live cloud data rendering with resilient offline fallbacks.
- **Visual Admin CMS (`admin.html`)**: Interactive dashboard protected by PIN authentication to update Profile, Hero, Highlights, Technical Skills, Projects, Career Milestones, Credentials, and About Story & Diagnostic Terminal.
- **Zero-Dependency Core**: Pure HTML5, Tailwind CSS CDN, Lucide Icons, and Vanilla JavaScript.

- **Admin Dashboard**: [admin.html](admin.html)
